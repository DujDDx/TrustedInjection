## 4. 逐事件离群

只看文档级可比指标（句数比、jac2、cont2）；照抄/新增/导语/句序是单篇的 0/1 或序数量，单篇离均值远是必然的，只能按语料均值判。

| 事件 | 项 | 实测 | 偏离 |
|---|---|---:|---:|
| e05 | PD.cont2 | 0.333 | +0.143 |
| e09 | WD.cont2 | 0.677 | +0.107 |
| e17 | PD.cont2 | 0.348 | +0.158 |

3/20 = 15%。PD 的 cont2 偏高集中在两个事件，机制是"借用的两句恰好是通稿里最独特的两句"。要压的话，把 PD 的借用句数从 2 降到 1、或按相似度挑最不独特的两句，都能解决，但会同时压低 PD 的 jac2（现在 0.126，已高于目标 0.11）。**暂不改**，因为均值在带内，且改动会牵动另一个已达标的指标。

## 5. 标签审计与错误链

| 检查 | 结果 |
|---|---|
| 标签与操作一致（单向硬约束） | **622/622 = 100%**，违反 0 |
| 篡改（值改错） | 20 个事件各 1 处，40 对判定（含二跳）全对 |
| 错引（事实真、来源假） | 20 个事件各 1 处，40 对全对 |
| 二跳继承 | 60 对全对（每事件抄 3 句、含 2 处错误） |
| 事实键异常 | 16 句 / 642 句 = 2.5%（见下） |
| 同一事实多句承载 | 0 处 |

16 句事实键异常分两类：

- **6 句"未知事实键"**：模型把材料的整句笔记当成事实键返回（如 `"Housing association reports 500 empty flats"`），分值匹配失败后保留了模型给的字符串。这批句子的事实标签不可信，训练时按不可用处理。
- **10 句"锚点不全"**：模型把锚点写成了别的形式。多数是拼写变体（`community centre` → `center`），少数是真丢（`HQ` → `headquarters`），还有 1 句写了材料里没有的细节（"Fog rolls off the coast every morning at 6am."）。**这 1 句属于编造，不是格式问题。**

审计判据在 P2 期间改过三处，都是第一版判错、不是数据错：

1. 二跳与**父文档**比而不是与通稿比（`origin` 说的是"从谁那里来"）。
2. 被篡改 / 被错引的句子不参与"照抄必须像照抄"的硬约束——改数字或追加来源之后本来就不再像通稿（实测一句 0.538→0.438 只是因为句尾多了 `, Finch Capital said.`）。
3. 锚点比对按**词**而不是按子串：`310m GBP` 与 `GBP 310m` 是同一件事，子串比对会把语序变化判成缺失。

## 6. P2 期间改的四处（都是实测踩出来的）

| 问题 | 实测现象 | 改法 |
|---|---|---|
| 导语保留 0.750、照抄 0.571（前 4 事件） | 24 句改写里 5 句相似度 ≥0.50（最高 0.765，模型直接回原句），既顶高 copy 又顶高 lead | ① `hard_rewrite` 对不达标句再抽一轮更激进的改写；② `wd_layout(exclude_lead=True)`，判"不保留导语"时彻底不用通稿第 1 句 |
| 自采句与通稿撞车 | 16/156 句"自采"相似度 ≥0.50（ND 复述通稿那两条事实时写得几乎同句） | `decontaminate`：只改这些句子，不动标签与句序；已生成的 20 个事件用 `fix_copy_leak.py` 一次性修完（16/16 修好） |
| 导语/句序比例写死 | P1 用固定三模式 (T,F)(F,T)(T,T)，lead 恒为 0.667（目标 0.53） | 按 0.53 / 0.72 逐篇随机抽；打乱概率取 0.72 而不是 0.64，因为"末位提前"的打乱下均值 = 1−p/2 |
| 篡改与错引对任意事件不可用 | 脚本写死 `7%→9%` 与 `Ofgem`；4 个事件"没有可篡改的复制句" | 错值按原数字推算（保量纲、避开已有数字、裸年份改成相邻年）；错引来源从事件自己的专名里按"机构名 > 多词专名"挑，并排除公司自己 |

## 8. 复现

```bash
cd experiments/provenance_sym_20261030
# 1) 20 个事件的事实包（写作者起草 + 机械校验，约 14 分钟）
TI_BASE=http://192.168.0.104:8818 python3 gen_events.py --n 24 --out events_p2.jsonl
# 2) 20 事件 × 5 篇（约 35 分钟）
TI_BASE=http://192.168.0.104:8818 python3 struct_p2.py \
  --events events_p2.jsonl --out-dir . --start 0 --end 20
# 3) 篡改 + 错引 + 二跳（纯后处理）
for f in p2_e[0-9][0-9].json; do python3 add_tamper.py "$f" --out "${f%.json}_t.json"; done
# 4) 审计与汇总
python3 audit_p1.py p2_e*_t.json
python3 p2_summarize.py p2_e[0-9][0-9].json
```
