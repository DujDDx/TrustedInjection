## 2. 文档与事实分配

### 2.1 每个事件、每个分支生成四篇

| 文档 | MATERIAL（行序随机打乱） | 事实条数 | 用于 |
|---|---|---:|---|
| A | f1 + 从其余 n−m−1 条共有事实中随机抽 n−2m−1 条 | n−2m | Set A、Set B |
| C | A 的 n−2m 条 + 从剩下 2m 条中随机抽 m 条 | n−m | Set A |
| B | A 的带标签原文（按句切开）+ m 条 B 独有事实 | n−m | Set A、Set C |
| Bf | A 的带标签原文（按句切开） | n−2m | Set B、Set C |

"剩下的 2m 条"指 A 没拿到的 m 条共有事实，加上 m 条 B 独有事实。

四篇使用 v1.1 §6.1 的同一份提示词，只有种子和 MATERIAL 不同。Bf 的审计在 v1.1 §6.3 的基础上增加一条：Bf 的标签集合等于 A 的标签集合。

### 2.2 结构对称性

以 n=5、m=1 为例。共有事实 c1–c4，B 独有事实 b1；A 拿到 3 条，没拿到的那条记为 c′：

| C 抽到 | 事实集合 | B 与 C 的关系 |
|---|---|---|
| c′（概率 1/2） | A ⊂ B，A ⊂ C；B 独有 b1，C 独有 c′ | 各有一条对方没有的事实，条数相同 |
| b1（概率 1/2） | A ⊂ B = C | 事实集合完全相同 |

两种情况下，B 与 C 在结构上都无法区分，判断谁抄了 A 只能靠措辞。

Set B 中 A 与 Bf 的事实集合完全相同；按 Q1 的默认做法，两个分支的值也完全相同。A 与 Bf 之间有派生关系这一点，从字面重合看得出（A–Bf 0.27）；但谁是派生，只能靠措辞判断。这个方向能否识别、靠什么识别，由 D7 测量。

### 2.3 B 独有事实由脚本随机指定，主体事实 f1 除外

我在 Phase 0 写出 n 条事实，其中哪 m 条作为 B 独有事实，由脚本按事件随机抽取，不由我指定。这样 B 独有事实不会集中在某一类内容上（例如总是"赞助商"），避免"这类事实只出现在 B 中"成为线索。

**主体事实（U8）**：每个事件的 f1 交代事件主体（会议名、公司名、球队、地点等），它：

- 不参加 B 独有事实的抽签；
- 总是分给 A，因此也总在 C、B、Bf 中（C 的前 n−2m 条与 A 相同；B、Bf 读 A 的原文）。

其余 n−1 条事实按原规则随机分配，各篇事实条数不变。原因：P0 的 107 条事实中，有 58 条用"The company""the conference"这类回指主语。如果点明主体的那条事实被抽走，整篇报道就只能写"the company"，不像真实新闻。

代价：f1 永远不会成为 B 独有事实，也永远不会被 A 漏掉。每个事件 f1 都由四篇文档共同陈述，这对四类文档一样，不构成角色线索。

### 2.4 打乱顺序

- A、C 的 MATERIAL：事实卡行随机打乱后再给模型。C 中与 A 相同的 n−2m 条，行文与 A 的卡片完全一致，只是顺序不同。
- B、Bf 的 MATERIAL：A 的句子随机打乱；B 的独有事实随机插入其中。
- 打乱后，A 中依赖前文的指代（例如 "the event"）可能失去先行词。审计只检查标签，这类问题留给人工抽查（§6）。

## 3. 填值与三个 Set

### 3.1 填值

| 文档 | Duplicate 分支 | Rumor 分支 |
|---|---|---|
| A | Truth | Truth |
| C | Truth | B 的每条 Rumor 事实以 1/2 概率"镜像"到 C：C 中同一事实的全部值换成 B 的 Rumor 值；未镜像的填 Truth（U5） |
| B 的独有事实 | Truth | Truth |
| B 中转述 A 的值 | Truth | 随机选 1–2 条转述事实填 Rumor（转述事实为 2 条时选 1 条），其余填 Truth |
| Bf | Truth | Truth（U4） |

镜像的取舍：你说"随机取其中一半"，我按"每条 Rumor 事实各自以 1/2 概率镜像"执行，并在全量上检查镜像比例在 50% ± 5 个百分点内。同一事件有两条 Rumor 事实时，可能一条镜像、一条不镜像，池中的不一致模式更混杂。如果你的意思是按事件整体镜像（一个事件要么全部镜像、要么全不镜像），改一行即可。

B 的 Rumor 事实本来就只从它转述 A 的事实中选，所以一定是 A 的事实，也一定出现在 C 中，可以镜像。

按上表，每篇文档的填值与它所在的 Set 无关（B 在 Set A 与 Set C 中填法相同，Bf 在 Set B 与 Set C 中填法相同），所以每个分支每篇文档只填一次，并记录每个值的字符区间与版本（truth/rumor）。变化的只有标签（§3.3）。

### 3.2 三个 Set（每个分支各一套）

| Set | 三个通道 | 每事件数据对数 |
|---|---|---:|
| A | (A, B, C) | 6（全部排列） |
| B | (A, Bf, X)，X 为其他事件的一篇 A 或 C | 6 |
| C | (X1, D, X2)，D 随机取 B 或 Bf（各 50%）；X1、X2 为其他事件的 A 或 C，允许来自同一事件，但不取同一篇 | 6 |

- 每个分支每事件 18 对，两个分支共 36 对；六类按构造为 1:1:1:1:1:1。
- 规模：试点 20 个事件 720 对，正式 400 个事件 14,400 对。
- X 从同一分支、同一数据划分中抽取，只用 A 或 C，不用 B、Bf。
- 你写的 Set C 是 "Any_B"。这里在 B 与 Bf 中随机取，让 Set C 同时覆盖两种派生文档。

### 3.3 逐 token 标签

只标占位符值所在的 token；非标签 token 记 -100（沿用 v1.1 §8.2）。dim1：1 = 传抄，0 = 独立。dim2：1 = 编造，0 = 核实。

| Set | 文档 | dim1 | dim2 |
|---|---|---|---|
| A | A、C 的全部值，包括 C 中镜像了 Rumor 的值 | 0 | 0 |
| A | B 中转述 A 的值 | 1 | Duplicate 为 0；Rumor 中填了 Rumor 的为 1，其余为 0 |
| A | B 独有事实的值 | 0 | 0 |
| B | A、X 的全部值 | 0 | 0 |
| B | Bf 的全部值 | 1 | 0（你的规定：Bf 全部为 Duplicate-核实） |
| C | X1、X2 的全部值 | 0 | 0 |
| C | B 或 Bf 中转述 A 的值，包括 Rumor 分支中填了 Rumor 的值 | 0（来源不在池中） | 0（U7：不是传抄，就不可能是编造） |
| C | B 独有事实的值 | 0 | 0 |

C 抽到 B 的独有事实时，这条事实同时出现在 B 和 C 中，两边都标 0。这是"内容相同、但都是独立报道"的样本。

### 3.4 编造标签的分布

按你的规定，Bf 在 Set B 中全部标核实。所以 dim2 = 1 只出现在 Rumor·Set A 的 B 上，约占全部数据对的 1/6；在这些数据对里，也只有 B 的 1–2 条事实为正例。训练时 dim2 的正例很少，可能需要按类加权，权重在训练计划中再定。

Rumor·Set A 中镜像带来的一种情况：C 的某个值与 A 不同，但标为核实（0）。按你的规定，C 是独立报道，不判编造。所以"与 A 不一致"本身不等于编造，只有"抄了 A 又与 A 不一致"才是编造。

Set C 中 B 的 Rumor 值也标 0（U7）。同一篇 B、同一个 Rumor 值，在 Set A 中标编造（池中有 A），在 Set C 中标核实（池中没有 A）。模型只能依据池内关系区分这两种情况；如果它学会凭"值看起来不合理"判编造，在 Set C 上会被罚。这也是 Rumor 值不需要做得合理的原因。

## 7. 已决定的问题

| 编号 | 问题 | 决定 |
