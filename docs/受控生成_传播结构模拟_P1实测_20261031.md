## 2. 口径更正：包含率是精确率

P0 的 `counter_structure.py`：

def cont(a, b):
    return len(a & b) / max(1, len(b))
...
"doc_cont2": cont(grams(tb, 2), grams(tp, 2)),   # b=通稿, p=报纸版 → 除以 |p|

## 5. 四条构造经验（P2 直接复用）

1. **事实表不能写成句子。** 写成完整新闻句，模型在 PD/ND 里逐字照抄，事实表就成了所有文档共享的模板——v1.2 的模板泄漏换个层级重现。必须用电报式笔记。
2. **提示词必须逐字相同，把 outlet 和长度写进材料块。** 但材料块里的 `outlet:` 会被模型当成正文写进文档（实测 ND 多出一句 "The report was published by the Western Mail."），必须在提示词里声明这两行是指令不是事实。
3. **改写强度只能按相似度选，不能靠形容词调。** "用自己的话"→0.05，"最小改动"→0.60，中间没有稳定落点。做法是同一提示词抽 2–3 次，取与原文 3-gram 相似度落在 [0.22, 0.48) 且最接近目标的候选。**没有候选合格时必须取最接近的，不能退回原句**——退回原句会把改写句变成逐字照抄。
4. **复制句不是逐字复制。** COUNTER 的 `copy@0.7` 只有 0.35 而 `copy@0.5` 是 0.47，说明真实照抄多数落在 0.50–0.70（报纸会改称谓、加电头）。逐字搬运会把 WD 的包含率顶到 0.65。
5. **复制哪几句、按什么顺序，必须程序随机化。** 只复制前缀、按原序输出会让"导语保留"与"句序保持"恒为 1.0（COUNTER 0.53/0.64），下游可以用位置线索解题。

锚点不能靠正则推断：`[\d,]*` 会吞掉后随逗号（`2027,` ≠ `2027`），`\s*(?:%|bn|m|p)?` 会把下一个词的词首字母当单位（`850 positions` → `850p`）。这两个坑造成过 5/25 误报。

## 6.5 篡改、错引与二跳（§3.4）

做成**后处理**而不是生成时操作：生成器已过结构与锚点验收，动它有回归风险；而篡改本身是纯字符串操作，不需要模型。

三条链：

1. **值篡改**：把 WD_1 里一句复制句的一个数字改错（`7%`→`9%`），标 `tampered` + `tamper{from,to}`。事实假、来源真。
2. **错引来源**：把 WD_1 里另一句的句尾追加 `, Ofgem said.`，标 `forged`。事实真、来源假。
3. **二跳**：`HOP2` 照抄 WD_1 的三句（含上面两句），`parent=WD_1`。相对父文档是忠实转抄，相对通稿则继承了篡改与错引。

| 事件 | 篡改 | 错引（被错引句的原 origin） | 二跳 | 审计 |
|---|---|---|---|---|
| g11 | `f1` 7%→9% | `f7` 12.4p 分红（rewritten） | 抄 #0/#3/#1 | 一致 40/40 |
| g22 | `f1` 7%→9% | `f3` 850 岗位（copied） | 抄 #0/#2/#1 | 一致 40/40 |
| g33 | `f1` 7%→9% | `f3` 850 岗位（rewritten） | 抄 #0/#1/#2 | 一致 40/40 |

合计 120/120 一致，硬约束违反 0，事实键异常 0，重复承载 0。三事件都实现了"1 篡改 + 1 错引 + 二跳继承 2 处"。

**两个审计判据的修正（都是第一版判错，不是数据错）**

1. **二跳必须与父文档比，不是与通稿比。** 第一版拿通稿做基准，`HOP2` 有两句报"说是照抄但相似度 0.375 / 0.190"——因为被抄的那句本身是 WD_1 的改写句，对通稿本来就不像。`origin` 说的是"这句从谁那里来"，二跳的"照抄"只需像它的父文档。改成按 `parent` 取基准后，这两句相似度 1.0。
2. **篡改句的锚点必然对不上，那是定义不是错误。** 第一版把 6 句 `tampered` 计入"事实键异常"。现在单列为"篡改后锚点不符（预期）"：每事件 2 句（WD_1 与 HOP2 各一句），异常计数归零。

**错引源必须与该事实无关。** 第一版按"复制句 + 无归因"挑，g11 与 g33 都落到了"Ofgem 已展开调查"这句上，追加 `, Ofgem said.` 只是重复，构不成错引。现在排除 `FORGE_SRC` 已出现在句中、或该事实本就归因于它的事实键（`f6`/`n6`/`n10`）；若无合格复制句则退到改写句（g11 即如此，错引标签说的是"给了一个没说过它的来源"，与是否照抄无关）。P1 的三个事件用 `--forge-src Ofgem` 显式指定，保持本表已记录的结果不变；P2 各事件没有 Ofgem，来源按"机构名 > 多词专名 > 其他专名"从事件自己的专名锚点里挑（只按频次挑过一版，P2 实测挑到地名，拼出 `, Deeside said.` 这种病句——地名不是背书人）。

**这条链能说明什么、不能说明什么。** 能说明的是：标签与操作一致，错误可以沿转抄链继承而不被结构指标察觉（HOP2 的 jac2/cont2 与一篇正常二跳文档无异）。不能说明的是：任何模型能检出这类错误——本数据集只提供带标签的负例，检出能力要另外训练与评测。

## 7. 未解决：句长（已决定按 B 接受）

三类词数比全部偏低，根因是生成的句子比真实新闻短约 1/3。这不是参数问题：

- 真实 PA 通稿约 14 词/句，报纸版 17 词/句；我们通稿 12–16 词/句，派生版 11–13 词/句。
- 在提示词里要求"完整新闻句、带归因与连接从句"只把通稿句长提到 13–16 词，派生版几乎没动。
- 约束来自"一句一事实"：一条事实只有一两个数字和专名，模型没有材料把它写长；写长就必须加背景从句，而背景从句本身就是未被声明的事实。

**用户 2026-10-31 决定取 B：接受现状，不放开"一句一事实"，不补背景从句字段。**

据此的验收口径收窄为：

| 项 | 是否作为 P2 验收 |
|---|---|
| 句数比（0.62 / 0.92 / 1.85） | 是，硬指标 |
| 文档级 jac2 与 cont2 | 是，硬指标 |
| 照抄 / 新增比例（τ=0.50） | 是，硬指标 |
| 词数比（0.76 / 1.08 / 2.12） | **否**，只作记录，方法节说明"派生文档句长偏短" |
| ND 新增比例 0.955 vs 0.88 | **否**，作为句长偏短的下游效应记录 |

方法节须写明：本数据集的文档级重合度与句数比例按真实传播结构校准，但**句子长度低于真实新闻**，因此依赖句长的指标（词数比、以 0.20 为界的"新增"判定）不能与真实语料直接比较。任何用本数据集训练/评测的结论都不得依赖句长特征。
