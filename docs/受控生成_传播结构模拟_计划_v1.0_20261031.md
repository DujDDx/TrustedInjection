## 1. 为什么走这条路

v1.2 的 4 句模板集把每条事实压成一句、每句都带署名、没有标题/导语/引语/背景。它压住了基线，但离真实新闻太远：模型学到的是"模板里的事实绑定"，不是"谁抄了谁"。用户 10-31 要求生成内容尽量符合真实传播结构，本计划就是把传抄拆成可执行的操作，用真实语料校准参数。

## 2. 依据：COUNTER 实测（P0 已完成）

### 2.1 口径

COUNTER：600 对乌尔都语报道，每对是同一事件的两篇，前者为通讯社通稿（543/600 出自 APP），后者为一家报纸的版本；`classification` 是这一对的属性——WD 135 对、PD 288 对、ND 177 对。句子按 `۔ ؟ !` 切分（乌尔都语句号后常无空格）。句间相似度取"词级 3-gram Jaccard"与"字符级 4-gram Jaccard"的较大值，因为乌尔都语词形变化多，纯词级会把改写误判成新增。

### 2.2 结构特征（均值）

| 特征 | WD | PD | ND | 说明 |
|---|---:|---:|---:|---|
| 句数比（报纸版/通稿） | 0.62 | 0.92 | 1.85 | 报纸版平均 4.3 / 7.1 / 12.2 句 |
| 词数比 | 0.76 | 1.08 | 2.12 | |
| 照抄句比例（τ=0.50） | **0.47** | 0.05 | 0.02 | |
| 照抄句比例（τ=0.30） | 0.64 | 0.12 | 0.04 | 阈值敏感性 |
| 新增句比例（相似度<0.20） | 0.24 | 0.71 | 0.88 | |
| 句序保持（LIS/匹配句） | 0.64 | 0.18 | 0.08 | |
| 删尾比例 | 0.47 | 0.86 | 0.95 | |
| 导语保留 | 0.53 | 0.09 | 0.04 | |
| 标题 Jaccard | 0.18 | 0.05 | 0.03 | |
| 文档级 2-gram Jaccard | 0.35 | 0.11 | 0.06 | |
| 文档级 2-gram 包含率 | 0.57 | 0.19 | 0.10 | |

文档级 2-gram Jaccard 区分 WD+PD 与 ND 的 AUROC = **0.813**（包含率 0.863），与交接 v2.0 §6.1 引用的 0.810 一致，口径可复算。

### 2.3 三条必须记住的读法

1. **"完全派生"不等于逐字照抄。** 一个 WD 对的通稿 2-gram 只有 57% 出现在报纸版里。报纸会改写：`9` 写成 `نو`、`عالمی بلائینڈ کرکٹ کپ` 换成 `بلائنڈ کرکٹ ورلڈکپ`、电头换成本地分社。所以照抄比例要按 0.47 设计，不是 1.0。
   > **2026-10-31 更正**：本句把"包含率"解释成召回，但 P0 代码是 `cont(b,p)=|b∩p|/|p|`，即精确率（报纸版 2-gram 有多少来自通稿）。0.57/0.19/0.10 只有按精确率才与 jac2 自洽（见 P1 实测 §2）。读法应是"报纸版有 57% 的 2-gram 来自通稿"，不是"通稿有 57% 出现在报纸版"。
2. **ND 的重合不是零。** 独立报道同一事件，专名、数字、常用搭配必然重合（2-gram Jaccard 0.06、包含率 0.10）。任何"重合即派生"的基线都会在这里出错，这正是难负例的来源。
3. **句序/删尾/导语三个指标只在匹配句上算**，PD、ND 匹配句很少（p25 为 0），数值不稳定。拟合参数时以 WD 为准，PD/ND 用"少量借用 + 大量自采"的比例控制，不照搬这三个均值。

### 2.4 没测准的一项

**归因密度**：实测 WD 0.24 / PD 0.25 / ND 0.27，三类几乎无差别，说明词典（6 种乌尔都语归因表达）覆盖不足，不是真实无差别。引号密度 0.04、电头出现率 0.59–0.67 也无区分度（电头是体裁常量）。这一项**不作为拟合参数**，只作数量级参考；要用必须请母语者扩词典后重测。

### 2.5 语言限制

COUNTER 是**乌尔都语、巴基斯坦报纸**。我们要生成英语。句数、照抄比例这类结构可能受语言与报纸惯例影响，直接迁移到英语没有依据。英语对应语料是 METER（PA 通稿 → 英国报纸，有 WD/PD/ND 标签），此前因许可未取得。**本计划的参数只在"乌尔都语结构"意义上成立**，英语试点必须同时报告"与 COUNTER 对齐"和"英语是否合理"两件事，不能把前者当作后者。

## 3. 构造方案

### 3.1 事件结构

一个事件 = 一篇通稿 W + 若干下游：

| 角色 | 读什么 | 由谁产生 |
|---|---|---|
| W 通稿 | 事实卡 | LLM 写 |
| WD 完全派生 | W 全文 | 程序复制 + 程序删除/重排 + LLM 改写 |
| PD 部分派生 | W 全文 + 自采材料 | 程序选句 + LLM 改写 + LLM 自采 |
| ND 独立 | 事实卡的另一组事实 + 自己的材料（不看 W） | LLM 写 |
| 二跳 | 某篇下游全文 | 同 WD，父文档换成该下游 |

同源兄弟：两篇下游都转自 W、彼此无派生关系。它们字面重合高但没有派生，是真实新闻里最难的负例，也是本方案相对 v1.2 人为诱饵的主要改进。

### 3.2 写作操作必须一致（关键约束）

v1.1 §4.4 的教训：派生提示词多两句话，探针就能到 0.906。所以**"照抄/删除/重排"绝不能写进提示词**，只能由程序执行：

- 所有文档用同一个提示词："读下面的材料，写一篇 N 句的报道，只写材料里有的事实。"
- 差别只在**材料内容**：W 读事实卡；WD/PD 读 W 的句子；ND 读另一组事实。
- 复制句由程序直接搬运，LLM 从不被告知"这一句要照抄"。
- 改写由 LLM 做，输入是**单句或连续 2–3 句**，输出改写后的句子，提示词里只有"用你自己的话重写这几句"。

这样措辞继承只来自"读了源文本"，不来自提示词差异。代价是逐句改写可能不连贯，见 §6 风险 2。

### 3.3 标签

**句子级**（主标签，精确到句）：

| 操作 | 标签 |
|---|---|
| 程序复制的句子 | derived，字面重合高 |
| LLM 改写自第 k 句 | derived，字面不同、语义同 |
| 自采句子 | independent |
| 数字被改错的那句 | fabricated / tampered（相对父文档） |
| 下游忠实复制错误句 | 相对父文档 verified，相对通稿 tampered（继承错误） |

**文档级**：WD / PD / ND / 二跳。

标签由操作记录直接给出，不依赖相似度阈值。这是相对 v1.2 的主要优势：v1.2 的标签虽然也从计划表算，但计划表本身泄漏（交接 v2.0 §5.2）。

### 3.4 编造嵌入

在传播链的某一跳改数字，下游忠实转抄：

- 第 1 跳改错 → 该句 tampered（相对 W）
- 第 2 跳照抄 → 该句相对父文档 verified、相对 W tampered
- 归因编造：某句写"据 X 报道"，而 X 从未说过 → forged

这与 v1.2 的两维标签定义兼容，但错误沿链条传播，比 v1.2 的"单点篡改"更接近真实。

## 5. 试点与验收（20 事件）

### 5.1 做什么

1 个事件原型（5 篇：W、WD×2、PD、ND）人工通读，确认连贯性与结构合理，再扩到 20 个事件（约 100 篇）。

### 5.2 验收

| 项 | 标准 |
|---|---|
| 结构对齐 | 8 个结构特征的均值与 §2.2 同类差 ≤ 0.10；文档级 2-gram Jaccard 落在 WD 0.35 / PD 0.11 / ND 0.06 附近 |
| 标签 | 操作记录与事后内容核对 100% 一致；无"程序说是复制、实际被改写"的句子 |
| 提示词一致 | 所有文档的提示词逐字相同（材料不同），脚本可查 |
| n-gram 基线 | 分层报告：整体（应接近真实，2-gram AUROC 0.75–0.85）与难层（低重合派生、同源兄弟，应接近 0.5） |
| 人工抽检 | 10 篇通读，句间衔接可接受，无模板痕迹 |
| 不宣称 | 不因为整体 n-gram 高就说方法无效，也不因为难层接近 0.5 就说任务可解 |

## 6. 风险

1. **语言迁移未验证**（§2.5）。乌尔都语参数用在英语上可能不合理。缓解：试点同时报告"与 COUNTER 对齐"与"英语是否自然"，两者分开；若冲突以英语自然为先，并如实说明参数来源不同。
2. **逐句改写不连贯**。真实改写是段落级的。缓解：改写以连续 2–3 句为单位；标签仍按句 1:1 对齐；不连贯就退回段落级改写并接受标签粒度变粗。
3. **LLM 过度改写**，使改写句的 2-gram 重合低于真实值，文档级 Jaccard 达不到 0.35。缓解：改写提示只给"同义改写"约束，不给"大幅改写"；试点后按实测调整复制句比例。
4. **程序复制与"同一写作操作"原则的张力**。复制是程序行为，提示词没有差异，但文本里确实存在逐字相同的句子。这是真实传播的事实，不是构造缺陷；但要在方法节里写明"字面重合由程序引入，措辞继承由同模型改写引入"，两者分开评估。
5. **20 事件的统计量太小**。分布对比只能看量级，不能做检验。试点只用于"结构是否可行"，不作方法结论。
